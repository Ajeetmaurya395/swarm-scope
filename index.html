PSO in 60 seconds

Imagine birds searching a valley for the lowest point. Each bird remembers the lowest spot it has seen (personal best) and hears about the lowest spot anyone has seen (global best).

Every step, each bird blends three urges into a velocity: keep flying the way it was going (inertia), return to its own best (cognitive), and head for the group's best (social). Random weights r₁, r₂ ∈ [0,1) keep the search from being too predictable.

Shortcuts: Space play/pause, → step, Shift+→ one iteration, ← back, R reset. Click a particle to inspect it.

    Worked example: checked against a hand calculation
    
  
    
    
    
      
    Setup (same as most textbook PSO examples)
    
      
    Minimise f(x, y) = x² + y² on [−4, 4]². Three particles, all starting at rest (v = 0). w = 0.5, c₁ = c₂ = 1. To make the arithmetic hand-checkable, each particle draws one r₁ and one r₂ per iteration (used for both x and y). The values come from the table on the right.
    
      
    
        
    Particlex⁰r₁, r₂ (iter 1)r₁, r₂ (iter 2)
    
        
    P1(2, 2)0.3, 0.50.4, 0.7
    
        
    P2(−1, 3)0.5, 0.20.6, 0.3
    
        
    P3(1, −1)0.8, 0.90.2, 0.5
    
      
    
      
    Iteration 1
    
      
    f: P1 = 4+4 = 8, P2 = 1+9 = 10, P3 = 1+1 = 2 → pbest = start points, gbest = P3 (1, −1), f = 2.
    
      
    P1: v = 0.5·0 + 1·0.3·(0) + 1·0.5·((1,−1)−(2,2)) = 0.5·(−1,−3) = (−0.5, −1.5) → x = (1.5, 0.5)
    
      
    P2: v = 0 + 0 + 1·0.2·((1,−1)−(−1,3)) = 0.2·(2,−4) = (0.4, −0.8) → x = (−0.6, 2.2)
    
      
    P3: v = 0 + 0 + 0.9·(0,0) = (0, 0) → stays at (1, −1). The leader at rest doesn't move: a known PSO weakness.
    
      
    Iteration 2
    
      
    f: P1 = 2.25+0.25 = 2.5 (better than 8 → new pbest), P2 = 0.36+4.84 = 5.2 (new pbest), P3 = 2. gbest stays P3, f = 2.
    
      
    P1: v = 0.5·(−0.5,−1.5) + 0.4·(0) + 0.7·((1,−1)−(1.5,0.5)) = (−0.25,−0.75) + (−0.35,−1.05) = (−0.6, −1.8) → x = (0.9, −1.3)
    
      
    P2: v = 0.5·(0.4,−0.8) + 0 + 0.3·((1,−1)−(−0.6,2.2)) = (0.2,−0.4) + (0.48,−0.96) = (0.68, −1.36) → x = (0.08, 0.84)
    
      
    P3: v = (0, 0) → stays.
    
      
    Iteration 3 (evaluation)
    
      
    f: P1 = 0.81+1.69 = 2.5 (not better), P2 = 0.0064+0.7056 = 0.712 (new pbest), P3 = 2. gbest → P2 (0.08, 0.84), f = 0.712.
    
      
    Note: in iteration 1 the cognitive term is always 0, because each particle's personal best is where it stands.
